# 贡献者行为准则（Contributor Covenant）

[English](https://github.com/clouddea/yang-base/blob/main/CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.md)

## 我们的承诺

作为成员、贡献者与维护者，我们承诺让参与本社区的每个人都不受骚扰，无论其年龄、体型、可见或不可见的残障、民族、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教或性认同与取向。

我们承诺以有助于建设开放、友好、多元、包容、健康社区的方式行事与互动。

## 我们的标准

有助于营造积极环境的行为包括：

- 对他人表现出同理心与善意
- 尊重不同的观点、立场与经验
- 给出并坦然接受建设性反馈
- 承担责任、向受我们错误影响的人道歉，并从经验中学习
- 关注的不只是个人最优，而是整个社区的最优

不可接受的行为包括：

- 使用性化的语言或图像，以及任何形式的性关注或性示好
- 挑衅、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下的骚扰
- 未经明确许可发布他人的隐私信息（如住址或邮箱）
- 其他在职业场合中可被合理认为不当的行为

## 执行责任

维护者负责澄清并执行可接受行为的标准，并对任何他们认为不当、威胁、冒犯或有害的行为采取适当且公正的纠正措施。

维护者有权也有责任删除、编辑或拒绝不符合本准则的评论、提交、代码、wiki 编辑、issue 及其他贡献，并在适当时说明处理理由。

## 适用范围

本准则适用于所有社区空间（issue、PR、Discussions，以及为项目运营的任何聊天渠道），也适用于个人在公共场合正式代表社区时。

## 执行

遭遇辱骂、骚扰或其他不可接受行为，可通过仓库的 **Security → Report a vulnerability** 私密渠道向维护者报告，或在 GitHub 上直接联系维护者 [@clouddea](https://github.com/clouddea)。所有投诉都会被及时、公正地审查与调查，并尊重报告者的隐私与安全。

## 执行指南

维护者在判定后果时，会参照以下社区影响分级：

### 1. 纠正（Correction）

**社区影响**：使用了不当语言，或其他被认为不专业、不受欢迎的行为。

**后果**：维护者发出私下书面警告，说明违规性质以及为何不当，可能要求公开道歉。

### 2. 警告（Warning）

**社区影响**：单次事件或一系列行为造成的违规。

**后果**：警告并说明继续该行为的后果。在指定期限内不得与相关人员互动，包括不得主动接触执行本准则的人员；也不得在社区空间及社交媒体等外部渠道互动。违反可能导致临时或永久封禁。

### 3. 临时封禁（Temporary Ban）

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在指定期限内禁止与社区进行任何形式的互动或公开交流；期间不得与相关人员有任何公开或私下互动。违反可能导致永久封禁。

### 4. 永久封禁（Permanent Ban）

**社区影响**：表现出持续违反社区标准的模式，包括持续的不当行为、对个人的骚扰，或对某类人群的侵犯与贬损。

**后果**：永久禁止在社区内进行任何形式的公开互动。
